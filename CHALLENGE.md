Challenge: Build an agentic system capable of resolving software engineering issues in a codebase.

Your system should be able to handle:
- receiving a issue/ticket describing a bug or feature
- root-cause analysis (if issue is a bug)
- implementation of the feature or bug fix
- testing of the implementation
- posting a PR to GitHub

You have full creative control to decide how it should work, and may use any tools available.

You have access to an example repo called doc-summarizer which you'll use as the test case for your agent.





Part 1: Architecture (45 mins)
Consider the problem and design your system architecture. Please feel free to ask us questions, do research, and use AI or other tools freely. Show how you think through problems, and ultimately create the design document you'll use in Part 2.
